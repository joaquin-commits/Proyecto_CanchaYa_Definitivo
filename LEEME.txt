PROYECTO CANCHAYA - EVALUACIÓN PARCIAL 1 DSY1104

INICIO
Abrir index.html en el navegador.
No requiere servidor, backend, base de datos, API ni frameworks.

OBJETIVO TÉCNICO
- HTML5 semántico y navegación entre páginas.
- CSS personalizado en archivo externo.
- Diseño responsive sencillo.
- JavaScript básico concentrado en validaciones de formularios.
- Mensajes de error y sugerencias personalizados.

IMPORTANTE
Los registros, pagos, modificaciones y eliminaciones son demostrativos.
No se utiliza localStorage ni se simula una base de datos.
